# آمادگی انتشار در استور

## انجام‌شده در کد
| مورد | توضیح |
|---|---|
| نسخه‌گذاری | `versionName` از `package.json` (الان ۱.۱.۰) و `versionCode` = شمارهٔ اجرای CI. هر بیلد عدد بزرگ‌تری دارد، پس آپدیت در استور پذیرفته می‌شود. |
| بیلد قابل تکرار | نسخهٔ Capacitor و افزونه‌ها ثابت شده است. یک نسخهٔ تازهٔ Capacitor دیگر بی‌خبر بیلد را خراب نمی‌کند. |
| هدف SDK | Capacitor 8، با target/compile SDK 36 (حداقل اندروید ۷). |
| نسخهٔ امضاشده | اگر Secretهای کی‌استور در GitHub تعریف شوند، علاوه بر APK دیباگ، **APK و AAB امضاشده** هم ساخته می‌شود. |
| امنیت مانیفست | پشتیبان ابری خودکار برای داده‌های مالی خاموش است (`allowBackup=false`)، ترافیک HTTP ناامن ممنوع است، و گیرندهٔ آلارم یادآور از بیرون اپ قابل صدا زدن نیست. |
| WebView | بدون `viewport-fit=cover`، پس محتوا هیچ‌وقت زیر نوار وضعیت/ناوبری نمی‌رود. CSP حداقلی هم اضافه شده است. |
| حریم خصوصی | متن سیاست حریم خصوصی در `docs/privacy-policy-fa.md` آمده و خلاصه‌اش در منوی راهنما. |
| اعلان‌ها | کانال‌های جدا برای «تراکنش‌های بانکی» و «یادآورها». مجوز اعلان در اندروید ۱۳ به بالا درخواست می‌شود. |

## کارهایی که صاحب اپ باید انجام دهد
1. **ساخت کی‌استور (فقط یک بار، و حتماً از آن نسخهٔ امن نگه دارید):**
   ```
   keytool -genkeypair -v -keystore hesab-release.jks -alias hesab -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 hesab-release.jks
   ```
   این چهار Secret را در GitHub (Settings → Secrets and variables → Actions) تعریف کنید:
   `HK_KEYSTORE_BASE64`، `HK_KEYSTORE_PASSWORD`، `HK_KEY_ALIAS`، `HK_KEY_PASSWORD`.
   ⚠️ اگر کی‌استور گم شود، دیگر هیچ آپدیتی روی همان اپ منتشر نمی‌شود.
2. **سیاست حریم خصوصی:** متن `docs/privacy-policy-fa.md` را روی یک آدرس عمومی بگذارید و لینکش را در صفحهٔ اپ در استور وارد کنید.
3. **مجوز پیامک:**
   - در **Google Play** باید فرم «Permissions Declaration» را برای دسته‌بندی *SMS-based money management* پر کنید.
   - کافه‌بازار و مایکت فرم جداگانه ندارند، ولی توضیح کاربرد پیامک را در شرح اپ بنویسید.
4. صفحهٔ اپ در استور: آیکن ۵۱۲×۵۱۲، تصاویر صفحه، شرح کوتاه و بلند، و دسته‌بندی «مالی».
5. برای انتشار از خروجی `hesab-ketab-release` استفاده کنید (AAB برای Google Play، APK برای کافه‌بازار و مایکت).

## چرا فایل HTML تکه‌تکه نشد
هیچ استوری چنین چیزی نمی‌خواهد. اپ از فایل محلی داخل خود APK بارگذاری می‌شود و حجم یا تعداد فایل روی بررسی استور اثری ندارد. شکستن یک فایل ۳۴ هزار خطی به چند فایل، ریسک خرابی عملکرد را بالا می‌برد بی‌آنکه سودی برای کاربر داشته باشد. برای همین همهٔ تغییرات این مرحله به‌صورت لایه‌ای و بدون دست‌کاری منطق موجود اعمال شده است.
