# حساب‌کتاب برای آیفون — راهنمای ساخت، نصب و تست

این نسخه همان `index.html` نرم‌افزار اندروید است که با Capacitor روی iOS اجرا می‌شود. ظاهر، جدول‌ها، محاسبات، پشتیبان و تجزیهٔ پیامک همان کد اندروید است. ساخت اندروید هیچ تغییری نکرده است.

## وضعیت این نسخهٔ آزمایشی

| بخش | وضعیت |
|---|---|
| همهٔ جدول‌ها، محاسبات، گزارش‌ها، پشتیبان و بازگردانی | ✅ همان کد اندروید |
| ثبت پیامک بانکی با برنامهٔ «میان‌برها» (اکشن «ثبت پیامک بانکی») | ✅ ساخته شده — روی گوشی واقعی هنوز تأیید نشده |
| چسباندن دستی پیامک («ثبت تکی و گروهی پیامک‌ها») | ✅ |
| لینک `hesabketab://sms?text=…` | ✅ |
| خواندن صندوق پیامک مثل اندروید | ❌ iOS به هیچ برنامهٔ عادی اجازه نمی‌دهد |
| ویجت‌ها، اعلان یادآورها، قفل Face ID | ⏳ هنوز ساخته نشده |
| خروجی PDF/اکسل | ⚠️ ممکن است روی iOS ذخیره نشود؛ باید تست شود |
| به‌روزرسانی داخل برنامه (APK) | ❌ در iOS پنهان است (اپل اجازه نمی‌دهد) |

حداقل نسخهٔ iOS: **۱۶** (برای اکشن میان‌برها). برای «اجرای فوری» اتوماسیون پیام، iOS 17 به بالا پیشنهاد می‌شود.

## ۱. اجرا روی شبیه‌ساز (بدون ساختن)

1. در گیت‌هاب، بخش Actions ← «Build iOS (simulator, unsigned)» ← آخرین اجرای سبز ← فایل `hesab-ketab-ios-simulator` را دانلود و باز کنید (`App.app`).
2. Xcode را از App Store مک نصب کنید و یک بار باز کنید (اجزای اضافه را نصب می‌کند).
3. Xcode ← منوی Xcode ← Open Developer Tool ← **Simulator**.
4. فایل `App.app` را روی پنجرهٔ شبیه‌ساز بکشید و رها کنید؛ آیکون «حساب کتاب» روی صفحه می‌آید.

## ۲. ساختن روی مک‌بوک خودتان

پیش‌نیاز: Xcode، و Node.js نسخهٔ ۲۲ (از nodejs.org).

```bash
git clone https://github.com/JustPlanB/Home-Calculator.git
cd Home-Calculator
git checkout claude/github-project-access-kffazw
npm ci
node scripts/build-web.js index.html www/index.html
npx cap sync ios
npx cap open ios
```

در Xcode، بالای پنجره یک آیفون شبیه‌ساز انتخاب کنید و ▶ را بزنید.

## ۳. نصب روی آیفون واقعی (Apple ID رایگان، بدون اپ‌استور)

1. آیفون را با کابل به مک وصل کنید و روی گوشی «اعتماد به این کامپیوتر» را بزنید.
2. Xcode ← Settings ← Accounts ← «+» ← Apple ID خودتان را اضافه کنید.
3. در پروژه: ستون چپ «App» ← زبانهٔ **Signing & Capabilities**:
   - «Automatically manage signing» روشن.
   - Team: همان «(Personal Team)».
   - اگر خطای شناسهٔ تکراری داد، **Bundle Identifier** را به چیز یکتا عوض کنید، مثلاً `ir.hesabketab.app.sepehr`.
4. بالای پنجره آیفون خودتان را انتخاب کنید و ▶ را بزنید.
5. روی آیفون:
   - Settings ← Privacy & Security ← **Developer Mode** را روشن کنید (گوشی ری‌استارت می‌شود).
   - Settings ← General ← VPN & Device Management ← گواهی خودتان ← Trust.

محدودیت Apple ID رایگان: نصب **۷ روز** اعتبار دارد؛ بعدش دوباره گوشی را وصل کنید و ▶ را بزنید (داده‌ها نمی‌پرند). حداکثر ۳ برنامه روی هر گوشی.

## ۴. ثبت خودکار پیامک بانکی با «میان‌برها»

آیفون اجازهٔ خواندن پیامک به برنامه‌ها نمی‌دهد. راه جایگزین، اتوماسیون شخصی برنامهٔ «میان‌برها» است که خود کاربر یک بار می‌سازد (داخل نرم‌افزار هم: منو ← «ثبت خودکار پیامک با میان‌برها»):

1. حساب‌کتاب را یک بار باز کنید (تا اکشنش در میان‌برها ثبت شود).
2. برنامهٔ **میان‌برها (Shortcuts)** ← زبانهٔ **Automation** ← «+» ← **Message**.
3. **Message Contains**: یک کلمه از پیامک‌های بانک، مثل «بانک» یا «مانده». (فیلتر Sender فقط مخاطبان ذخیره‌شده را می‌شناسد.)
4. **Run Immediately** را انتخاب کنید و «Notify When Run» را خاموش کنید.
5. اکشن **«ثبت پیامک بانکی»** (حساب کتاب) را اضافه کنید؛ در «متن پیامک» از **Shortcut Input** گزینهٔ **Content** را بگذارید.
6. Done.

از آن به بعد هر پیامک بانکی در صفِ روی خود گوشی می‌ماند و با باز کردن حساب‌کتاب، همان باکس تأیید نسخهٔ اندروید برایش می‌آید. رمز یک‌بارمصرف و تبلیغ ثبت نمی‌شود و هر پیامک فقط یک بار ثبت می‌شود. هیچ چیزی از گوشی بیرون فرستاده نمی‌شود.

**تأییدنشده:** این‌که اتوماسیون پیام روی همهٔ نسخه‌های iOS واقعاً بی‌سؤال اجرا شود، فقط روی گوشی واقعی با سیم‌کارت قابل تست است.

**تست بدون سیم‌کارت (شبیه‌ساز یا گوشی):** در میان‌برها یک میان‌بر معمولی بسازید: اکشن «ثبت پیامک بانکی» با یک متن نمونهٔ پیامک بانکی، اجرا کنید، بعد حساب‌کتاب را باز کنید. یا در Safari آدرس `hesabketab://sms?text=...` را باز کنید.

## فایل‌های iOS

- `ios/App/App/HkIos.swift` — اکشن «ثبت پیامک بانکی» (App Intents)، صف روی گوشی، افزونهٔ `HkIosSms`، و ثبت افزونه.
- `ios/App/App/Base.lproj/Main.storyboard` — ریشهٔ صفحه `HkBridgeViewController`.
- `ios/App/App/Info.plist` — طرح لینک `hesabketab://`.
- `index.html` — بخش «نسخهٔ iOS»: خواندن صف، لینک، راهنمای داخل نرم‌افزار، پنهان کردن بخش‌های مخصوص اندروید.
- `.github/workflows/ios-build.yml` — ساخت بدون امضا برای شبیه‌ساز روی مک گیت‌هاب.
