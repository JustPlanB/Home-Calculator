# کارگاه — قواعد ساخت اپ

این فایل قرارداد بین صاحب پروژه و هر جلسه‌ی Claude است. هر چیزی که می‌سازید باید با این قواعد جور باشد.
ظاهر و رفتار از اپ **حساب‌کتاب** (`../index.html`) گرفته شده است. اگر چیزی اینجا نیست، اول در حساب‌کتاب نگاه کنید و همان را کپی کنید.

## قانون‌های طلایی

1. **واژه‌نامه پایین قانون است.** وقتی کاربر می‌گوید «جدول»، یعنی کامپوننت `createTable` با همه‌ی جزئیات همان بخش. نسخه‌ی ساده یا تازه نساز.
2. **رنگ، اندازه و فاصله فقط از `css/tokens.css`.** هیچ `#hex` یا `px` تازه‌ای بیرون از آن فایل ننویس. مقدار تازه لازم شد، اول توکن بساز.
3. **آیکن فقط از `js/ui/icons.js`.** SVG دست‌نویس و ایموجی داخل UI ممنوع. آیکن تازه = یک ورودی تازه در `ICONS`، با همان سبک (خطی، ضخامت ۲، سرخط گرد، شبکه‌ی ۲۴).
4. **هر عملگر یک شکل ثابت دارد.** افزودن همیشه `+` آبی، حذف همیشه `✕` قرمز، ویرایش `✎`، بازگشت فلش راست با متن «بازگشت». نوع دیگری برای همان کار نساز.
5. **متن UI فارسی، ارقام فارسی، RTL.** رقم با `toFa/fmtNum`، تاریخ با `fmtJ` (شمسی). تاریخ ذخیره‌شده رشته‌ی `1405-07-25` است.
6. **متن کاربر هرگز با `innerHTML` وارد نشود.** فقط `h()` از `core/dom.js`. (`html:` فقط برای آیکن‌های داخلی.)
7. **هر جزء تازه به `styleguide.html` هم اضافه شود** (`js/styleguide.js`) و عکس تم شب و روز گرفته شود.
8. **صفحه‌ها منطق خالص ندارند.** منطق بدون DOM در `js/core/` می‌ماند و تست دارد.

### «جدول» یعنی چه — مشخصات کامل

وقتی می‌گویم **جدول بساز**، همه‌ی این‌ها را دارد:

- **قاب:** حاشیه ۱px، گوشه ۱۶، عنوان وسط‌چین درشت بالا («نام — بخش»).
- **سربرگ:** آبی‌سرمه‌ای (`--tbl-head`)، متن سفید، وسط‌چین، **چسبیده به بالا** هنگام اسکرول.
- **ستون اول «ردیف»** با شماره‌ی فارسی؛ **ستون آخر (چپ)** ضربدر قرمز حذف (اگر `onDelete` داده شود).
- **خط‌های شبکه** `--tbl-line`، ردیف‌های زوج با `--row-alt`، ارتفاع ردیف حداقل ۵۲.
- **انواع ستون:** `text` (راست‌چین، زیرخط اختیاری `sub`)، `num` (با `unit`)، `money` (جداکننده‌ی `,`، سبز مثبت و قرمز منفی)، `date` (شمسی)، `percent`، `select` (دکمه‌ی «انتخاب» ← شیت)، `status` (چیپ رنگی ← شیت)، `check`، `person` (آواتار + نام)، `progress`، `custom`.
- **ویرایش درون‌خطی با دو ضربه** روی سلول (لمس و ماوس)؛ Enter ثبت، Esc لغو، ورودی نامعتبر ← توست خطا و برگشت به مقدار قبل. زیر جدول جمله‌ی «برای ویرایش، دوبار روی فیلد ضربه بزنید».
- **جمع پایین** برای ستون‌هایی که `total: 'sum'` دارند.
- **حذف** همیشه با مودال تأیید.
- **دکمه‌ی افزودن ردیف** (`addPill`) پایین، سمت راست.
- **حالت خالی:** یک ردیف با `emptyText`.
- **عرض:** در ۳۹۰px جا می‌شود؛ در عرض کمتر، فقط اسکرول افقی (سربرگ ثابت می‌ماند). ستون اضافه نکن مگر لازم باشد.
- جدول **کنترل‌شده** است: داده را نگه نمی‌دارد، با `onCellChange / onDelete / onAdd` خبر می‌دهد و صفحه با `setRows` دوباره می‌کشد.

## ساختار پوشه‌ها

```
css/tokens.css      ← تنها منبع رنگ/اندازه (تم شب و روز)
css/base.css        ← ریست و بدنه
css/components.css  ← همه‌ی کامپوننت‌ها (پیشوند k-)
css/screens.css     ← چیدمان مخصوص صفحه‌ها
js/core/            ← بدون DOM: fa، jalali، store، tasks، router، dom
js/ui/              ← icons، controls، table، overlay، forms
js/screens/         ← یک فایل برای هر صفحه
js/data/seed.js     ← داده‌ی نمونه (همه‌ی تاریخ‌ها نسبت به امروز)
styleguide.html     ← نمایش زنده‌ی همه‌ی اجزا
tools/shots.cjs     ← عکس‌گیری از صفحه‌ها
tests/              ← تست منطق خالص
```

## محیط‌ها (Environments)

- **صفحه‌ی اصلی:** هدر ثابت (منو، پروژه، تاریخ) + کارت خلاصه + سه جعبه کاشی + نوار پایین (افزودن، پیشرفت کل، جستجو).
- **صفحه‌ی داخلی:** همان هدر ثابت + `screenHead` + محتوا. نوار پایین ندارد.
- **روی صفحه:** مودال، شیت، توست. هیچ صفحه‌ی تمام‌صفحه‌ی دیگری نساز.

## قانون‌های دامنه (از یادداشت صاحب پروژه)

- کار ناتمام روزهای قبل، در «باقی‌مانده از روزهای قبل» می‌آید؛ کار انجام‌شده به فهرست کلی می‌رود (`tasksForDay`).
- وقتی همه‌ی کارهای امروز تیک خورد، بنر سبز «همه‌ی کارهای محول‌شده‌ی امروز انجام شد».
- ناظر هر روز گزارش می‌دهد؛ پیشرفت نسبت به گزارش قبل نمایش داده می‌شود (`reportDelta`).
- سفارش خرید از دل گزارش ناظر ساخته می‌شود و در فهرست مسئول خرید می‌آید.
- «انبار»، «مالی»، «مدارک»: فعلاً صفحه‌ی «به‌زودی» با شرح محتوای برنامه‌ریزی‌شده.

## اجرا و تست

```bash
cd kargah && python3 -m http.server 8765        # http://localhost:8765
node --test tests/*.test.mjs                            # تست منطق
NODE_PATH=$(npm root -g) node tools/shots.cjs out/   # عکس همه‌ی صفحه‌ها، شب و روز
```

آدرس `?today=1405-07-25` امروز را ثابت می‌کند (برای عکس و تست).
