# حساب کتاب — نسخه Capacitor

این پروژه از فایل HTML فعلی ساخته شده و رابط/منطق موجود را داخل Capacitor قرار می‌دهد.

## نکات مهم
- داده‌های اصلی برنامه همچنان در `localStorage` خود WebView روی دستگاه نگهداری می‌شوند. فایل فعلی همین معماری را دارد.
- Firebase فقط برای همگام‌سازی داده‌های یک «کد خانواده» بین دو گوشی استفاده می‌شود؛ منطق فعلی برنامه از REST API فایربیس استفاده می‌کند.
- پشتیبان کامل فعلی به صورت JSON تولید می‌شود و در محیط Android از طریق سیستم فایل/دانلود گوشی قابل ذخیره است.
- کد HTML از قبل `window.onBankSmsReceived(smsText)` را برای اتصال گیرنده SMS نیتیو آماده کرده است؛ افزونه SMS نیتیو را در مرحله بعد می‌توان اضافه کرد.

## ساخت APK فقط با موبایل
نیازی به Android Studio نیست. پروژه را در GitHub قرار دهید و از مسیر **Actions → Build Hesab Ketab APK → Run workflow** اجرا کنید. پس از پایان، از بخش **Artifacts** فایل `hesab-ketab-debug-apk` را دریافت و روی گوشی نصب کنید.

## توجه
این خروجی Debug برای نصب و تست است. برای انتشار در Google Play یا نصب به‌عنوان Release باید APK امضاشده با keystore ساخته شود.
