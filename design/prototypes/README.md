# نمونه‌های طراحی (مرحلهٔ صفر)

سه جهت بصری برای حساب‌کتاب، فقط برای مقایسه. هیچ ارتباطی با نرم‌افزار اصلی، ساخت APK یا تست‌ها ندارد.

- `index.html`: یک فایل مستقل؛ بالای صفحه طرح (۱ دفتر، ۲ فیروزه، ۳ پیشخوان)، صفحه (اصلی/تراکنش‌ها) و حالت (روشن/تاریک) انتخاب می‌شود.
- داده‌ها ساختگی و برای هر سه طرح یکسان است.
- فونت وزیرمتن (و نسخ برای عنوان‌های طرح ۲) از Google Fonts بارگذاری می‌شود؛ بدون اینترنت فونت جایگزین دیده می‌شود.

مشاهده: فایل را در مرورگر باز کنید (روی گوشی تمام‌عرض، روی رایانه داخل قاب گوشی).
