# تثبیت سیستم طراحی (پیشنهادی، اجرا نشده)

ظاهر، چیدمان و رفتار فعلی حساب‌کتاب حفظ می‌شود؛ فقط مقدارهای ناهماهنگ یکدست می‌شوند.
هیچ‌کدام از این فایل‌ها در index.html، ساخت APK یا تست‌ها استفاده نمی‌شوند.

- `tokens.css`: توکن‌ها (رنگ تیره/روشن، ۹ پلهٔ نوشته، فاصله، ۵ گردی، سایه، اندازهٔ کامپوننت).
- `refine.css`: لایهٔ نمونه که مقدارهای پراکنده را به توکن‌ها برمی‌گرداند (یافته‌های F1 تا F10).
- `build-preview.js`: `node design/system/build-preview.js` ← `preview.html` = نرم‌افزار فعلی + لایه + کلید «قبل/بعد».
- `audit-report.html`: گزارش ممیزی با جدول‌های قبل/بعد و تصویر صفحه‌ها در هر دو حالت.

پوشهٔ `design/prototypes/` (سه جهت بصری تازه) کنار گذاشته شد؛ مسیر انتخاب‌شده تثبیت همین طراحی است.
